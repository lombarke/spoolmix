{# How to make and upload a printer template. Needs: template (or none), next #}
  1. Open your slicer and pick your printer and nozzle.
  2. Pick the color-mixing print process you print with (for example "0.10mm Color Mixing"), and change any process settings you always use. spoolmix keeps them; it only carries over a design's own supports, brim, infill and walls.
  3. Set up one filament per slot your printer has (4 for a 4-toolhead printer), using the filament presets you normally print with (material, temperatures). The colors don't matter: spoolmix fills in the right ones every time.
  4. Put any small object on the plate (a 20 mm cube is fine) and save the project (File → Save Project As… → .3mf).
  5. Upload that file here.

Replace it whenever you change its printer, nozzle, process or filament presets. Its number of filaments is the slot count spoolmix plans for.
